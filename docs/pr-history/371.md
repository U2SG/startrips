# PR #371 - Make PR communication exception-only

- **Base:** `cc9805a3c80eb4fd8ef6b7eb9492611748c0e932`
- **Scope:** Establishes the Startrips low-communication, high-evidence pull-request policy. GitHub Conversation becomes an exception channel rather than a progress log; routine state stays in commits, CI/checks, ONE `feature_list.json`, review state, and the per-PR ledger.
- **Behavior:** Normal implementation PRs use one concise fresh review request per CODE Source and one compact final `HANDOFF_REVIEW`; extra comments are reserved for human decisions or exceptional safety/blocker context. Routine CI/rebase/rerun/mergeability narration and per-finding fix narration are prohibited by default. Maintainers are zero-comment by default.
- **Files:** `CONTRIBUTING.md`, `docs/agent-pr-communication.md`, and this ledger only. No runtime, test, CI, deployment, product, or Backend behavior changes.
