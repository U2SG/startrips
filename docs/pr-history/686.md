# PR #686 - Route roads through a private GitHub Actions worker

- **Source head:** `e44419a44540eb25c113c29a1eb9023918fd06b2`
- **Scope:** Add a GitHub Actions worker provider (`server/routing/github-worker.ts`) that dispatches the private `U2SG/startrips-routing-worker` workflow, dedupes items, caches results, bounds jobs (3 concurrent, 6 items or 600 km summed direct distance per job), and accepts HMAC-signed results at `POST /api/internal/routing-worker/results` (own 2 MB limit, signature checked over the raw body before parsing). Interactive candidates and nearby road points use the existing 202 preparing flow; the background reconciler sends one job per Journey with viewed/edited Journeys first, skips test Journeys, and records over-400 km segments as `ROUTING_AREA_TOO_LARGE`. Self-intersections between parts of a route at most 3 km apart along it are tolerated. Static OSRM URLs still win; the builder remains the fallback.
- **User-visible change:** Road candidates, nearby road points and background snapping work wherever Geofabrik has data, including long rural legs; waits of a few minutes show 正在准备这段路线的道路数据，通常需要几分钟…, and the client waits up to 15 minutes.
- **Review fixes:** The P2 thread is fixed: a nearby road point lookup whose own corridor exceeds the job distance cap is refused with `ROUTING_AREA_TOO_LARGE` instead of being dispatched.
- **Follow-up:** Replace the temporary broad GitHub token on the host with a fine-grained token limited to the worker repository. Re-enable background snapping after the callback path is verified in production. Consider caching Geofabrik extracts in the worker.
- **Validation:** [Source CI](https://github.com/U2SG/startrips/actions/runs/37879461214) passed quick-checks, core, keepsake-render and all eight browser QA lanes; ledger/verify failed only because this ledger was absent. Worker runs on GitHub in test mode: a combined 6-item job succeeded in 9.3 min (peak 4.85 GB, no swap), Christchurch → Dunedin returned a 361 km route, nearby points for the reported rural start connected 3 of 3, and the reported 434 km route's only crossing is 301 m apart along it. Locally: typecheck and targeted server routing, route-snapping, config and routing-preparation tests.
