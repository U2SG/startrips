# PR #674 - Give a noted transit chapter its own stage row so its media is visible

- **Source head:** `ccd2e22d2f3aa5bd224972f39e16c777cb537caa`
- **Scope:** `src/styles/starlight-media.css` adds a two-row stage template, `fit-content(34%) minmax(0, 1fr)` with `align-content: stretch`, for `.journey-playback__stage:has(> .journey-playback__transit-media > .journey-playback__transit-note)`. A transit via (not a Stop, not anchored) that carries media and a short note renders the note (#595) as a sibling grid item ahead of its media inside a `display: contents` group; the #560 single-row rule left the media in an implicit 0 px row. `src/journey/playbackStageLayout.test.ts` pins the single-row template for a note-less transit chapter, the two-row template for a noted one, and the note's position ahead of the media in the overlay markup.
- **User-visible change:** In Playback, a route point that is not a Stop but carries photos and a note now shows its photos; before, only the note appeared and the photos were skipped (Bryce Canyon, Zion and Death Valley on the reported Journey).
