# PR #717 - Share only photos without people from one sentence

- **Source head:** `dac984b920df64ecb806abbeb28eb56df1cb588b`
- **Scope:** Share-intent proposals gain `mediaFilter: "no-people" | null`. `POST /api/intents/share/media` classifies the selected Journeys' photos on demand with `INTENT_VISION_MODEL` (previews inline as base64; batches of 48 unclassified photos per call, 3 concurrent, the dialog loops until none remain; one request per Atlas at a time), caching per asset and model in `media_person_classifications` (migration `0039_stiff_firestar`). Share grants gain an optional media scope (`share_grant_media` + `share_grants.media_scoped`) enforced on `/api/shared/journeys` and `/api/shared/assets/:id/read-url` through one shared predicate; excluded assets answer as nonexistent and a cover outside the payload is omitted.
- **User-visible change:** A sentence such as 「只分享风景图」 pre-selects Journeys, then lists the photos without people (with thumbnails and an excluded count) before Create. Guests of a filtered link see only those photos. Without a vision model the server says it cannot filter and Create waits until the owner chooses to share all photos.
- **Review fixes:** Owner review: a requested filter on a server that cannot classify blocks Create instead of silently sharing all photos. Adversarial review (Codex blocker): a failed or superseded re-submission no longer clears an active no-people filter; Create is also held when a ready result belongs to a different selection. Adversarial review (Opus): more than 48 unjudged photos are judged in batches instead of failing forever; concurrent filter requests per Atlas answer 409. QA: `story-media-handoff` exit-clone scoring ignores the 90° control for rotation-symmetric frames (it failed deterministically here and on main c8b43aa1).
- **Follow-up:** `GET /api/shares` does not yet mark photo-filtered links; no browser scenario for the cannot-filter branch; a fully timing-out batch can take minutes; `story-note-beats` flake tracked in #718.
- **Validation:** Local `pnpm typecheck`, `git diff --check`, `node --check`. CI run 39597626424 on the Source head: `core`, `keepsake-render` and all eight browser-qa shards green on the latest attempts; `story-media` needed two reruns for the unrelated `story-note-beats` flake (#718).
