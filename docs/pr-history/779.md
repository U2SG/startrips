# PR #779 - [iOS] 原生图谱主界面对齐 Web Mobile V2

- **Source head:** `4bc817d1e60bbeef9427f2ca9148ee2943471f7d`
- **Scope:** iOS 本地图谱场景复用 Web Mobile V2 的紧凑品牌栏、当前旅程卡片、时间轴、旅程详情抽屉和全部旅程选择器，取代原先独立的时间线与地点按钮条。新增按作用域和版本校验的 `switchAccess` 场景事件，账户切换经 AppRouter 与 AtlasSession 完成；图谱页隐藏多余的 SwiftUI 导航栏，Story 保留原生导航。WebKit 停止时提供不依赖 WKWebView 的原生「重新加载地球」恢复。
- **User-visible change:** iPhone 图谱主界面与手机网页一致：顶部品牌与账户、全部旅程按钮，可左右滑动切换的旅程卡片，点开后的详情抽屉可选择地点并打开故事；Story 文字按钮改为「上一页 / 下一页 / 整理与导出」。
- **Review fixes:** 根据用户截图修复旅程卡片在 iOS 上的触摸滑动（与鼠标/笔指针分开处理、末尾不循环、滑动后不误开抽屉），移除 Story 重复的感想面板，品牌字标改用可点击的 Web 签名动画按钮。
- **Follow-up:** 详情抽屉的授权封面、创建/编辑旅程、Home Base、日常、分享入口、安全区深色外壳与无障碍适配仍属 #775 后续工作。
