# PR #259 - Drive the Earth dive from the zoom authority instead of a mode switch

- **Source head:** `e53447192361f0aecdb09b863383f5d487691834`
- **Scope:** Addresses #252, phase A only: the state, progress and ownership contract for the Semantic Earth Dive. `src/scene/semanticZoom.ts` stays the single zoom authority and its published state now carries a `SemanticZoomSnapshot` - the band, the canonical clamped `zoom`, and a `localProgress` derived once from the boundary that opens `local` and the ceiling of the range - so no consumer re-derives a band or restates a threshold. `src/scene/earthDive.ts` is a new pure resolver over that snapshot plus a four-level `DetailReadiness` ladder (`unavailable` / `mounted` / `visual-ready` / `fully-settled`); it advances at most one stage per frame through `particle -> prewarm -> blending -> detail`, blends at `visual-ready` rather than waiting for tiles, releases asymmetrically (leaving needs the band to fall to `macro`), and returns an explicit `owner` that transfers exactly once on the commit edge. It contains no zoom value and no clock, both asserted by a source guard in `earthDive.test.ts`. `src/scene/LivingAtlasGlobe.tsx` resolves that state in one animation-frame loop and derives the stage and the input owner from it alone: the `earthMode` / `transitionTarget` / `targetReady` triple, the 12 s load timeout, the crossfade finish timer and the transition-status element are gone, the section publishes `data-earth-dive` and `data-earth-dive-owner`, and the persistent particle scene stops answering the wheel and the drag while the map owns the camera. `src/scene/detailedEarthModel.ts` gains `getEarthDiveHandoffFrame`, which maps the focus anchor and the same snapshot to a MapLibre centre and zoom and returns the identical frame at every mounted stage; `DetailedEarthMap` mounts from it, follows it with `jumpTo` while the particle globe still owns input, no longer flies to the same focus a second time, reports its readiness ladder, keeps every gesture handler disabled until ownership transfers, and publishes the projected anchor, the local latitude scale and its own zoom for measurement. `scripts/qa-earth-dive.mjs` and the `browser-qa / earth-dive` lane grade all of it in a browser at 1440x1024 against a new `?qaState=earth-dive` fixture.
- **User-visible change:** Zooming the particle Earth in now reveals the detailed map by itself, and zooming out returns, with no button press in either direction and no loading text: the detail surface is prepared invisibly from the regional band, is only revealed once it can actually draw, and keeps the place the user was looking at in the same position and at the same scale when it takes over. If the map cannot load, nothing changes on screen and the particle Earth stays fully usable. The existing `深入真实地图` / `返回粒子地球` control stays as an accessibility command for the same dive, and pressing it while a dive is still preparing now cancels it.
- **Review fixes:** Two Codex P2 findings, both verified against the code first. (1) Ownership transferred on the frame after the blend began, so one wheel notch crossing both progress cuts handed the gestures to a surface still fading in; the commit edge now has a final `blendPresented` gate, measured by the section from the detail layer's own computed opacity and passed in, which keeps the fix clear of the acceptance rule that no clock may enter the resolver. The same reviewer asked for the reverse direction to be delayed symmetrically and that half was refuted: #252 section 4 forbids "finish the old transition, then obey the user", the layer is `pointer-events: none` while it fades out, and the release writes the particle camera back, so a reversal is obeyed on the frame it happens. (2) A command-driven dive whose style never reached `visual-ready` had no exit, because `commandRequested` also short-circuits the band's own planet/macro exit and pressing the control again only re-set the flag; the control is now one command that cancels at any stage other than `particle`, and the release latch is cleared before the controller's no-change exit so a cancel resolving to the stage the band already wanted cannot latch and block later dives.
- **Follow-up:** The later #252 phases, deliberately not bundled here: MapLibre camera calibration polish and the real-device performance phase; the finite-DPR / drawing-buffer / covered-render suspension contract, which stays with #247 / ST-038 and is not duplicated here; removal of the permanent desktop mode chrome, whose fullscreen slice belongs to #253 and which must not come back as a smaller replacement pill; removal of the mobile `真实地图` action and the `mobile-v2__real-map` dialog and its Journey-sheet trigger in `src/journey/LivingAtlasApp.tsx`; and the Geographic Materialization particle progression. `DETAILED_EARTH_INITIAL_ZOOM` remains only as the floor for a genuine later focus flight.
