# PR #821 - Redesign the iPhone Story tools as a grouped native list

- **Source head:** `cc603931b5c69f1e3b14c5387178f1683b536f99`
- **Scope:** Rebuilds the iPhone Story 整理与导出 sheet as an insetGrouped list in the Night Flight style with four single-word sections (素材, 整理, 手记, 导出) and leading-aligned 44pt rows. Recovery rows appear only while the Journey has an unfinished upload (`PhotosImportModel.hasPending`); media to move are picked from a thumbnail grid instead of raw filenames, with destination pickers and the move button shown only after a selection; 生成 MP4 is the single primary button. Following #818, 导入手记 and 保存或分享影片 are no longer presented from inside the tools sheet: the tools sheet closes and the Story presents them from its `onDismiss`. Models, endpoints and identifiers are unchanged.
- **User-visible change:** The owner's Story tools read as one clean grouped list; recovery and move controls appear only when relevant; move picks photos by thumbnail.
- **Review fixes:** None.
