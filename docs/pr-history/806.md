# PR #806 - 恢复旅程之流自动播放，把当天手记移到侧面

- **Source head:** `6f216dc9f44ad843fe94121d11adb64f5a951364`
- **Scope:** 有手记的旅程之流使用原生滚动自动浏览。日期入口在对应站点旁，当天正文用独立面板显示。阅读优先采用原稿的第一人称，并整理可明确辨认的旧转述句式。
- **User-visible change:** 打开旅程后照片自动滚动。手动浏览或阅读某天手记会暂停，页首可以继续。桌面在右侧读当天手记，手机在底部读，页末仍能浏览全部手记。
- **Review fixes:** 空格键直接操作播放按钮，关闭当天手记后焦点返回原入口。
- **Follow-up:** 上线后用原来的美西旅程确认站点入口和阅读面板。
- **Validation:** [Source CI 43384970685](https://github.com/U2SG/startrips/actions/runs/43384970685) 产品、浏览器及 iOS 检查通过。浏览器用例验证播放暂停、按日阅读、面板打开时照片间距、第一人称和多种屏幕尺寸。Source 的 ledger 和 verify 等待本记录。
