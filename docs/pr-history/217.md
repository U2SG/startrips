# PR #217 - Remove global API rate limiter

- **Source head:** `85a4e5659db65104736f4057b4e8f8ceeb57d908`
- **Scope:** Removed the application-wide per-IP /api/* limiter, deleted its in-memory middleware and configuration/env surface, retained Better Auth's targeted auth rate limits, and added a regression test proving ordinary API traffic is not globally throttled.
- **User-visible change:** Normal Startrips navigation, Journey/media loading, playback, share reads, uploads, and other product API bursts no longer hit the app-generated RATE_LIMITED / Too many requests response after 60 requests in 60 seconds from one IP.
- **Review fixes:** Kept authentication abuse protection intact; cleaned the initial Windows editing artifacts; narrowed regression coverage to the middleware contract rather than a mocked route implementation detail.
- **Follow-up:** If a specific public/expensive endpoint needs abuse protection later, add endpoint-specific limits based on its actual cost/threat model rather than restoring a blanket /api/* bucket.
