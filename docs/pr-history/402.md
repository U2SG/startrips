# PR #402 - Execution guard sees its own supervisor on MSYS

- **Source head:** `39fa356f572a6ebd6da39fd3c7e857b90e1d116a`
- **Scope:** Control-plane distribution only: the duplicate-execution guard, the supervisor and launcher that publish their own Windows pids, the test module's import resolution, its regressions, and the control-plane workflow's shell syntax checks. No application, server or product source changes.
- **User-visible change:** A local Windows worker can start again. Since the previous distribution was activated, every run-loop iteration reported the supervisor that had just launched it as a competing execution and exited rc=6, so the supervisor retried on a ten-minute timer and the loop produced nothing while appearing alive. Behavior off MSYS is unchanged.
