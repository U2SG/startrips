# PR #654 - Light the Journey Book cover relief with a raking key light

- **Source head:** `c79420a061771c77a1e2da60f5fe115a7543b9d8`
- **Scope:** The 3D Journey Book front cover gets one material map beside its colour face (`paintCoverMaterial` in `journeyBook3dPainter.ts`), drawn from the same Route, mark and plate geometry.
  - R carries height: cloth 128; Route groove floor and start square 96, with the groove ramping over three concentric strokes at 1.1, 0.8 and 0.5 times the painted deboss width; stamped mark 104, from a second rasterisation of the v12 SVG in material colours; foil 104; plate 144.
  - G carries roughness: cloth 0.9, groove floor 0.85, foil 0.5.
  - B carries metalness: foil 0.85, everything else 0.
  - The map is attached only to face 0 as bumpMap (`bumpScale` 4), roughnessMap and metalnessMap via `JourneyBook3dScene.setCoverMaps`, and is disposed with the cover surface.
  - The pure `coverKeyLight(progress, reduced)` in `journeyBook3dModel.ts` poses the key light every frame: raking at 30° from the upper left (world -X/-Z) while the front cover is closed, easing back to the reading light by progress 1. It ignores progress below 0.1 (hover lift) and snaps at half way under reduced motion. It keeps a fixed distance, holds flat-paper irradiance constant, and scales the shadow normalBias with the angle.
  - The colour painter's deboss strokes are kept but lightened (alpha 0.07, start square 0.12).
- **User-visible change:** On the closed 3D book, the Route is a fine impression: thin lit and shaded walls with the cloth colour in the groove floor. The start square and stamped mark are pressed in, the plate stands slightly proud, and the foil destination has a metallic sheen. Opening the cover returns to the usual reading light.
- **Review fixes:**
  - **Shadow acne:** the first CI cover screenshots (run 37275419681) showed diagonal acne under the 30° light. The farthest PCF tap there needs about 0.0135 of normal offset, more than the 0.012 tuned for reading. The shadow normalBias is now 0.012 scaled by the same acne guard: about 0.021 at 30°, exactly 0.012 when reading. Map size, frustum, `bias` and PCF radius are unchanged.
  - **Owner feedback on run 37277780462:** the groove read as a dark, heavy tube. Its height-map width is halved, its floor raised from 72 to 96, `bumpScale` lowered from 10 to 4, and the painted strokes lightened.
  - Rebased onto `main@74ada3b9`.
- **Follow-up:** Foil roughness is 0.5, not the briefed ~0.3. Without an environment map, a 0.3 metal would read darker than the cloth. The extra texture is 1024 × 1280 RGBA8 (5,242,880 bytes, about 6.7 MiB with mipmaps), held only while the cover is within one spread.
- **Validation:** Local `pnpm install --frozen-lockfile`, `pnpm typecheck`, `git diff --check` and the pr-history validators. Unit tests for `coverKeyLight` and the material channel table, vitest, build and browser QA run in GitHub CI. The `journey-book-3d` lane's desktop-cover.png and phone-cover.png are the visual evidence.
