# PR #396 - Preserve cross-point reading provenance and return

- **Base:** `3806bdb7dc4d4410f045d85e5a6a9ccffe1676a3`
- **Source head:** `673169cbd834fdb73ec534bad3884d471006f573`
- **Scope:** Implements ST-082 / issue #378 as a narrow transient adjacent-Route-Point note reader on top of the existing Route Point context and ST-036 committed-observation contract. From an already selected source Route Point, only the current Journey's immediate previous/next Route Point with a real note may be opened transiently. The reader carries exact Journey + source Route Point + target Route Point provenance and never creates a second Story, generalized reading platform, new media sequence or domain entity.
- **User-visible change:** Route Point context may now offer restrained previous/next note-reading actions when the adjacent Route Point has a real note. Opening one shows a source-aware transient reader that names the target Route Point and Journey, explains that the current observation is unchanged, and offers an explicit Story escalation. Closing, Escape or Browser Back returns to the exact invoking Route Point; only explicit escalation may commit the target under the existing Story contract.
- **Return / commit contract:** Owner decision comment `5680741273` establishes transient source-bound reading. Explicit Close, Escape and Browser Back close only the reader and restore the invoking Route Point context without changing committed observation. Explicit Story escalation is the commit boundary: the target Route Point is committed through the existing context path before Story opens, so note-only/no-media targets return to the target under ST-036 even when there is no visual morph target. Ordinary Story A -> B browsing remains governed by ST-036 and is not replaced with unconditional BACK or a fixed index.
- **Authorization / invalidation:** `resolveCrossPointReading(...)` re-resolves source and target from the current scoped Journey DTO on each render. Journey ownership change, source deletion/move, target deletion/move, note removal or any other scope/provenance mismatch invalidates the transient reader instead of preserving stale content. Adjacent targets must be distinct from the selected source and retain their own Route Point note provenance; synthetic or generic atmosphere copy is not substituted.
- **Mobile / focus ownership:** The transient reader is a modal surface with existing focus/history ownership and does not take globe camera or Playback ownership. Compact/mobile V2 raises the reader above persistent header/chrome and the browser lane verifies pointer-hit ownership for both Close and Story escalation at 390x844. Reduced-motion keeps the reader nonspatial and source-bound.
