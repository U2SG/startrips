# PR #310 - Derive Quick Recap duplicate clusters from persisted content hash

- **Issue relationship:** `Refs #127` - ST-058 closes only the persisted exact-content identity input gap; issue #127 remains open for the broader deterministic media-digest and photo-first exploration.
- **Source head:** `36fb83ee1cbe8753a05c36573ad98b1f3ab098f8`
- **Scope:** ST-058 only. `quickRecapDigestsForJourney` now maps a non-empty persisted owner-media `contentHash` to `MediaDigestV1.similarity.duplicateClusterId`; null, undefined, and empty hashes produce no similarity signal. `JourneyMediaAsset` declares `contentHash?: string | null`. Focused tests cover the production runtime projection path where Journey-scoped media and the first Route Point share a content hash, validator parity, guest-shaped media without content hashes, and selection-summary rendering of `duplicate-cluster-representative`.
- **User-visible change:** Quick Recap can now truthfully explain an already-selected representative as `duplicate-cluster-representative` when byte-identical persisted media share the same content identity. The included asset-id set, omitted asset ids, chronology, chapter topology, dwell/trim values, and planned duration remain unchanged; unique/no-hash journeys retain the pre-change plan semantics. Raw content hashes are not exposed in UI or telemetry.
- **Review fixes:** Initial Source commit `fbb12f9` wired the persisted signal and added focused production-path tests. Follow-up Source commit `36fb83e` aligned the duplicate fixtures with the existing Quick Recap timing budget so the tests exercise duplicate-reason truthfulness without accidentally changing membership through an over-budget fixture. Exact-head automated review on `36fb83e` completed with no major issues.
- **CFAA / regression family:** The invalidated assumption was that production Quick Recap digests have no duplicate identity even though owner media already carries persisted `contentHash`. Regression coverage checks deterministic duplicate selection, validator re-derivation, runtime Journey-scoped projection into the first Route Point, selection-summary reason rendering, missing/null/empty-hash behavior, guest-shaped media, and invariance of membership/timing. This PR does not change server schema/routes/repositories/uploads, Full Playback, Quick Recap tempo/timing/topology, perceptual or near-duplicate hashing, technical quality scoring, owner pin/exclude intent, aspect-ratio/framing, Keepsake, AI/VLM, or cloud media analysis.
- **Follow-up:** Issue #127 remains open for the broader deterministic media-digest and photo-first exploration, including signals that do not yet exist in persisted data such as perceptual near-duplicate clustering, real media metadata and bounded technical-quality inputs. Those are not owned by ST-058.
