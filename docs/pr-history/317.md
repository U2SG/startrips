# PR #317 - Refine Earth Dive spatial handoff

- **Source head:** `cf04cc3b87ce9218fb99f1dad1ff6dcafa1997ec`
- **Scope:** Refine the Semantic Earth Dive renderer handoff only. Local wheel/pinch Dive reveals detail from the calibrated particle anchor rather than a full-frame dissolve, and ownership can transfer only after the same-frame particle/detail screen-space anchor and local scale agree. Particle frames carry the canonical semantic zoom from that render frame so a newer zoom snapshot cannot commit against an older anchor. MapLibre follows new particle frames through the imperative publish path; if a fully-settled stable frame is still outside tolerance, the existing Dive rAF requests bounded `retry` calibration that preserves the map's accumulated center correction instead of reseeding it. Hidden/prewarmed MapLibre mounts `interactive: false`; detail ownership restores the complete ordinary interaction contract, including sequential canvas focus, box zoom, touch pitch, pan/rotate, scroll/touch zoom, keyboard and double-click zoom. No second renderer, timer, state machine or semantic-zoom authority is introduced.
- **User-visible change:** Local zooming into detailed geography reads as the same place gaining detail from the current point of attention. Keyboard/accessibility Dive from planet/macro keeps the prior full-frame opacity handoff (900ms normal / 120ms Reduced Motion) instead of faking a completed radial reveal. The detail map is absent from Tab/input ownership while prewarming, becomes keyboard-reachable only when it owns the Dive, and leaves focus ownership again on the reverse handoff. If the detail style is unavailable, particle Earth remains the owner and continues answering gestures.
- **Review fixes:** CFAA and exact-head CI found three blockers on the previous source. (1) Non-local keyboard command was encoded as radial progress=1, which selected `transition:none`; non-local command now explicitly uses full-frame fallback, and non-local normal/reduced command is gated by readiness + opacity presentation rather than impossible local-scale alignment. (2) `interactive:false` created a `tabindex=-1` canvas and left default boxZoom/touchPitch disabled after ownership transfer; detail ownership now sets canvas `tabIndex=0` and restores boxZoom/touchPitch plus the pre-existing handlers, while particle ownership sets `tabIndex=-1` and disables them again. (3) exact-head CI reached fully-settled local progress 1 while alignment remained outside tolerance and no new particle frame arrived; stable non-converged frames now continue through the existing Dive rAF using a bounded two-pass retry mode that never resets the previously corrected center. The hard alignment gate remains unchanged. QA also distinguishes the ownership commit edge from later legitimate detail-owned wheel motion, so a user-driven detail camera is not incorrectly required to remain identical to the frozen hidden particle camera.
- **Follow-up:** This PR does not change map data/style fidelity, coastline quality, Route Point/Story media behavior, route-light grammar, Home Base, visited imprint, or brand/error-state motion. Synchronous calibration cost remains a targeted performance-watch item; it is bounded and no separate cadence was added.
