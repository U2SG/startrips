# PR #594 - Measure the globe drag threshold from the press point, not path length

- **Source head:** `6c7ca3051fa401686d3668fbfc5e5a15b45a5abd`
- **Scope:** Batch A of audit batch 2 in #586. The Earth measured its drag threshold against accumulated pointer path length; it now measures displacement from the point where the contact went down. `globePointerIntent` owns the new `globeDragDisplacementPx` helper and `rebaseGlobeDragSample` returns the press origin instead of a seeded distance. The renderer stores that origin and tests displacement against it.
- **User-visible change:** A slow wander in place no longer steals the tap. A trackpad two-finger nudge, or a hand resting on a trackpad, traced far more than the 6px threshold of path while the pointer never left a 2px neighbourhood of where it went down, so the Earth read an intended tap as a drag, claimed manual camera ownership and consumed the gesture, and the Route Point underneath never activated. A real drag still moves away from its press point, so it trips the same threshold at the same distance.
- **Review fixes:** The audit's own framing was confirmed against the code before changing anything, which also corrected its one line-number slip. A pinch collapsing into a one-finger drag no longer needs the fabricated `travel: alreadyConsumed ? threshold : 0` seed, because `started` is already true and the threshold is therefore never re-tested for that gesture. One source-text assertion in `LivingAtlasGlobe.test.ts` pinned the literal `isGlobeDrag(dragTravel)`; it was updated to the new variable name, and the contract that test actually guards — the threshold check precedes `claimManualInteraction()` and `dragStarted` — is unchanged.
- **Follow-up:** The rest of the globe's pointer honesty is deliberately not here. Pick-miss feedback and a cursor on the Earth are visual decisions that belong with the accessible-surface work and its screenshot baseline. Batches B, C and D of #586 remain open, and #76 establishes the Journey-wide cursor that #595 and #555 both build on.
- **Validation:** Acceptance is GitHub Actions only. Source CI run for `6c7ca305` is green on `core` (typecheck and the full `pnpm test`) and on all ten browser-qa lanes. Locally, only to locate problems and never as acceptance: typecheck clean, `vitest run src/scene/` 26 files and 405 tests green, and no `dragTravel` reference remains anywhere in `src`. This final commit changes only this ledger, and the ledger fast path proves the Source CI it reuses.
