# PR #323 - Quiet Home Base suggestion on the Atlas

- **Source head:** `ee84ad92468d8f839c57b16d6477cf6710a34abf`
- **Scope:** Implements ST-060 / issue #232 by wiring the ST-027 inference core into the Atlas. Adds an atlas-scoped `home_base_dismissals` table with drizzle-kit generated migrations, a dismissal read and write on `server/routes/home-bases.ts` whose Atlas comes only from `server/authorization/atlas-access.ts`, a pure `src/journey/homeBaseSuggestion.ts` mapping inference state and reason codes to the issue's evidence-phrased copy, a non-modal card rendered beside the Atlas timeline on desktop and in the planet state on compact mobile, a confirm action that creates a new period through the #231 write path, and a `browser-qa / home-base-suggestion` lane with `scripts/qa-home-base-suggestion.mjs`. `src/journey/homeBaseInference.ts` carries a bounded diff required by the owner's 2026-09-12T22:55:56Z comment: an optional `evidenceNotBefore` input and the extraction of dismissal matching into the exported `applyHomeBaseDismissalToInferenceResult`. Its thresholds, its state union, the `HomeBaseEvidenceReasonCode` union and the dismissal policy itself are unchanged. `homeBaseEvidenceDigest` now follows the versioned exact persistence protocol the owner approved on 2026-09-13T06:10:20Z: canonical `hbi-v2` whenever its exact form fits the 64 KiB per-digest budget, an exact lossless `hbi-v3` fallback beyond it that preserves region anchor, supporting Journey membership, start/end support flags and evidence dates, readers and matchers accepting both versions, and no proactive rewrite of rows already persisted as v2. The frozen V1 semantics — 25 km clustering, thresholds and states, hard-rejection precedence, the 90-day + 2-new-Journeys soft rule and guest/share isolation — are unchanged, and the contract is recorded by `src/journey/homeBaseInference.test.ts` in `Home Base evidence digest version compatibility contract`.
- **User-visible change:** A member whose Journeys repeatedly start and end near one region is now offered a quiet, non-modal card naming that region from their own Place Labels, explaining the evidence rather than announcing a conclusion, with confirm, 「暂时不用」 and 「不是<place>」 answers. The card never appears while Journey Story or Journey Playback is open, the Atlas stays interactive behind it, an answer survives a reload, an explicit rejection of one region survives answering about another, and confirming a move closes the previous period instead of overwriting it. Guests and shared Atlases see none of it.
