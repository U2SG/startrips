# PR #587 - Close six interaction-contract gaps from the front-end audit

- **Source head:** `303de8b6877f8e4403e3e66ce67dbb474aa03def`
- **Scope:** Batch one of the audit in #586. Five product fixes across three production surfaces: playback initial focus moved to the dialog root so Space pauses instead of exiting; a Composer dirty baseline with a nested alertdialog confirmation plus `beforeunload` so closing no longer destroys an authoring session; `--atlas-accent` (defined nowhere) replaced with `--atlas-acid` on the delete-undo control; the high-specificity `outline: none` removed from Composer text inputs so they share the app-wide focus ring; and a visible, announced WebGL2-unavailable notice on the persistent Earth. That guard's baseline was then corrected from identity to content. The merge of main also brought in #584, whose `route-candidates` lane and script this branch was missing. Two QA-harness corrections accompany them: the Composer close flow now asserts the new discard-guard contract, and the autoplay fixture gained a recorded-track stub that #584 independently added in the same place.
- **User-visible change:** Space now pauses playback instead of tearing down the playthrough; closing the Composer with unsaved work asks first and lands initial focus on 继续编辑, including when the only change was editing an already-existing Route Point or moving an already-picked photo; the delete-undo button renders its intended acid label colour; every Composer text input shows a focus ring; and a member on a machine without WebGL2 is told the Earth is unavailable and that manual coordinates still work.
- **Review fixes:** The composer-focus and composer-guard CSS from the first push regressed five browser-qa lanes. The discard-guard rule had been inserted between a comma-separated selector list and its declaration block, so `.journey-composer label > span`, `.journey-story-fields label > span` and `.journey-composer__discard-guard` shared one block, making every Composer label span a `position: absolute; inset: 0; z-index: 40` overlay that intercepted every click on the surface. An interim bisect that blamed the `outline: none` removal was itself wrong and was discarded; the accessibility fix stands and the underline was recoloured rather than thickened, because no global `border-box` exists and the thicker border reflowed the form on focus. The audit's desktop-Back finding was withdrawn on CI evidence: the `isMobileV2` gate is load-bearing. Re-reading the guard then exposed its own blind spot: comparing joined `draftId`s and the pending media *count* is silent about any edit that keeps identity and cardinality intact, so renaming an existing Route Point or reassigning a picked photo still discarded work without asking. `routeDraftFingerprint()` now digests the persisted Route Point fields and each pending file's identity and ownership.
- **Follow-up:** Desktop browser Back still leaves the Atlas with an open Story, which needs a desktop-side history owner rather than a removed `isMobileV2` gate. Batch two of #586 and the CSS token governance work remain unscheduled. The autoplay harness treats any console error as an invalid run, so every new client endpoint has to be added to its fixtures; #584 and this branch both discovered the missing recorded-track stub independently, which suggests that fixture list needs a cheaper way to stay honest.
