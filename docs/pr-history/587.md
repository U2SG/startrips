# PR #587 - Close six interaction-contract gaps from the front-end audit

- **Source head:** `a5d1d0cb1f44c097bc9568a82c8983cd2d094845`
- **Scope:** Batch one of the audit in #586. Five product fixes across three production surfaces: playback initial focus moved to the dialog root so Space pauses instead of exiting; a Composer dirty baseline with a nested alertdialog confirmation plus `beforeunload` so closing no longer destroys an authoring session; `--atlas-accent` (defined nowhere) replaced with `--atlas-acid` on the delete-undo control; the high-specificity `outline: none` removed from Composer text inputs so they share the app-wide focus ring; and a visible, announced WebGL2-unavailable notice on the persistent Earth. That guard's baseline was then corrected from identity to content (see Review fixes). Two QA-harness corrections accompany them: the Composer close flow now asserts the new discard-guard contract, and the autoplay reproduction fixture stubs the recorded-track read.
- **User-visible change:** Space now pauses playback instead of tearing down the playthrough; closing the Composer with unsaved work asks first and lands initial focus on 继续编辑, including when the only change was editing an already-existing Route Point or moving an already-picked photo; the delete-undo button renders its intended acid label colour; every Composer text input shows a focus ring; and a member on a machine without WebGL2 is told the Earth is unavailable and that manual coordinates still work.
- **Review fixes:** The composer-focus and composer-guard CSS from the first push regressed five browser-qa lanes. The discard-guard rule had been inserted between a comma-separated selector list and its declaration block, so `.journey-composer label > span`, `.journey-story-fields label > span` and `.journey-composer__discard-guard` shared one block, making every Composer label span a `position: absolute; inset: 0; z-index: 40` overlay that intercepted every click on the surface. An interim bisect that blamed the `outline: none` removal was itself wrong and was discarded; the accessibility fix stands and the underline was recoloured rather than thickened, because no global `border-box` exists and the thicker border reflowed the form on focus. The audit's desktop-Back finding was withdrawn earlier on CI evidence: the `isMobileV2` gate is load-bearing. Re-reading the guard then exposed its own blind spot: comparing joined `draftId`s and the pending media *count* is silent about any edit that keeps identity and cardinality intact, so renaming an existing Route Point or reassigning a picked photo still discarded work without asking. `routeDraftFingerprint()` now digests the persisted Route Point fields and each pending file's identity and ownership.
- **Follow-up:** Desktop browser Back still leaves the Atlas with an open Story, which needs a desktop-side history owner rather than a removed `isMobileV2` gate. The autoplay harness's recorded-track stub is a symptom worth watching: every new client endpoint must be added to the fixtures that enforce `errors.length === 0`, or it surfaces as a spurious lane failure. Batch two of #586 and the CSS token governance work remain unscheduled.
