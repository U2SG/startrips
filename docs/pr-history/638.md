# PR #638 - Add first-arrival route bloom and first-media cue

- **Source head:** `1e6a93fd0693afa3a436cb72a77c130a7dc83134`
- **Scope:** `handleSaved` detects the first Journey arriving in an empty Atlas: an initial-save arrival handoff with zero Journeys before the save. It sends a one-shot `routeArrivalBloom` request through `LivingAtlasGlobe` to `ParticleEarthScene`. The scene arms the request at the matching route flight and plays it only on that flight's natural settle. The route's final rendered Route Point gets one CSS glow bloom from `motionTokens.glow` idle to core/halo and back, using `--motion-journey` / `--motion-ease-out`. A manual camera claim, a different flight or dispose drops it. `JourneyStory.uploadFiles` detects the first media in a Journey that had none (never on retry) and shows `StartripsJourneyCue state="arrived"` before the success status line. Pure detection lives in `src/journey/firstJourneyMoments.ts` and `shouldArmRouteArrivalBloom`, with node-env unit tests.
- **User-visible change:** After the camera settles on the first Journey in an empty Atlas, its final Route Point glows once. The first successful media upload into an empty Journey shows the arrived cue next to the success message. Under reduced motion there is no bloom, and the cue is static.
- **Review fixes:** Codex P2: the persistent globe outlives Atlas owner remounts (organization switch), and each mount restarts its revisions. A new owner's first-Journey bloom could therefore be treated as already consumed. The request now carries a per-owner-mount `scope`, and the scene tracks the consumed `(scope, revision)` pair. Unit tests cover a same-scope replay (suppressed) and a new scope at revision 1 after a prior scope consumed revision 1 (plays).
- **Follow-up:** The suggested multi-placement upload (`uploadPlacementGroups`) does not show the first-media cue.
- **Validation:** Locally: `pnpm install --frozen-lockfile`, `pnpm typecheck`, `git diff --check` and the ledger validators. Authoritative: GitHub CI (vitest, browser QA and build). Visual feel-check delegated to the reviewer.
