# PR #786 - Keep the model's journal status and drop only unmatched claims

- **Source head:** `56dea3973258f597c82fd2427a8eadddd93fa00d`
- **Scope:** Journal AI import keeps the model's event status and drops only a date, clock or place claim that does not match its line (inheriting the chapter date when repeated). Chapter dates are checked against the whole chapter, events are matched by line, only omitted lines are degraded, identical chapters from one response are joined, and segments are ~1,500 characters with four concurrent calls. Only chapter boundaries and tool shape use the correction loop.
- **User-visible change:** A real 210-line journal that previously imported as entirely uncertain now keeps actual/planned/cancelled statuses, clock times and place references; only lines the model omitted need review.
- **Review fixes:** None beyond the original change; tests were updated to the new semantics.
- **Follow-up:** Owner-authorized local run of that journal on the production journal model: 108 s, 6 segments, 0 fallbacks, 0 degraded lines, 15/15 chapter dates matched. Production acceptance requires the owner's re-import after deployment.
