# PR #636 - Strip dev-only public files from production builds

- **Source head:** `b63246f788a8dc3944277aafc42865987bbdd979`
- **Scope:** A `production-public-boundary` Vite build plugin removes `artworks/`, `demo-media/`, `qa/` and `fonts/` from the build output in `closeBundle`, unless `STARTRIPS_KEEP_DEV_STATIC=1` is set. The files stay in `public/` for the dev server and for QA scripts that read them from disk. `story-autoplay-reproduction.yml` sets the flag because it serves a production build through `vite preview`. The PR deletes the unreferenced `earth/nasa-clouds-2048.jpg`, `earth/nasa-earth-surface-2048.jpg` and `favicon.svg`. It adds a vector `brand/startrips-v12-favicon.svg` built from the v12 mark paths and links it in `index.html`. Caddy now serves `/brand/*` with the `/earth/*` revalidating cache rule and drops `/fonts/*`.
- **User-visible change:** The browser tab shows a crisp vector favicon where SVG favicons are supported. Brand files are cached for an hour. The production site no longer serves the legacy archive images, demo media, QA fixture or Doto font.
- **Review fixes:** None.
- **Follow-up:** The `api` Docker image still copies `public/` through `COPY . .`.
- **Validation:** Locally: `pnpm install --frozen-lockfile`, `pnpm typecheck`, a standalone `tsc --noEmit` of `vite.config.ts`, and `git diff --check`. CI on the Source head passed build, tests, browser QA and Story autoplay reproduction. The ledger lane failed only because this file did not exist yet. The CI build logged 7,120,928 bytes stripped from `dist`, on top of the 1,216,444 bytes of deleted files.
