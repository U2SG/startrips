# PR #681 - Reduce production first-load bundle

- **Source head:** `ee4f95697af253d2669adf53b19b41290a2213c3`
- **Scope:** Add a deterministic bundle measurement (`scripts/perf-bundle-build.mjs`, `scripts/measure-bundle.mjs`, its node test, and a separate `perf-bundle` workflow that uploads `bundle.json`). Move Composer, itinerary import, Playback, Story and the Share dialog out of the production entry through `deferredSurface`, which preloads on idle, renders synchronously once loaded, shows the existing reader placeholder only when an open beats the preload, and reports a failed chunk instead of unmounting the Atlas. Fetch the wordmark goat show on idle, and split three and React into vendor chunks. `ci.yml`, the Vite proxy, CSS order and the scene readiness/reveal path are unchanged.
- **User-visible change:** The first screen downloads and parses less JavaScript: eager JS gzip falls from 510,638 to 350,222 B (-31.4%) on the `07d45972` base, and is 350,995 B after rebasing onto `d457db4b`. Repeat visits after an app-only deploy keep about 182 KB of it cached. If a surface is opened before its idle preload lands, the existing "正在打开…" placeholder shows briefly.
- **Review fixes:** Codex P2: the measurement now reads chunk imports from Rollup's syntax tree (`parseAst` from Vite) instead of a regex, so import-like text in strings or comments is no longer counted. A node test covers it.
- **Follow-up:** Browser QA runs on the Vite dev server, so production lazy-chunk timing is not covered by a browser lane. Runtime fetches of `/earth/*` data (for example `cities.json` and `ne_50m_land.geojson`) are outside the JS bundle and were not changed. The remaining eager JS is mostly three, react-dom, the particle scene and the Atlas shell.
- **Validation:** Each step was re-measured by the perf-bundle workflow (baseline run 37769737942; rebased Source run 37783023400, zero measurement errors). [Source CI](https://github.com/U2SG/startrips/actions/runs/37783023446) passed quick-checks, core (vitest and build), keepsake-render and all eight browser QA lanes; ledger/verify failed only because this ledger was absent. Codex reviewed `ee4f95697a` with no findings. Before the rebase, one story-media attempt hit the `journey-book-3d` 720 s cap on an older runner image with every assertion passing; its same-SHA rerun passed in 404 s. Locally: `pnpm typecheck`, `git diff --check`, `node --check` on the new scripts.
