# PR #292 - Add focus-aware local 10m coastline refinement

- **Source head:** `1882b8f8c173e6853ad04cee25ae453e59c1e47e`
- **Scope:** Issue #154, ST-013 only. Add the first bounded high-detail coastline slice for Hong Kong / Pearl River Delta by preprocessing Natural Earth 10m land offline into deterministic 2-degree chunks, loading only the active local neighborhood, and selecting that neighborhood from the existing canonical settled focus or the real surface inspection ray during free exploration. The near layer keeps the existing regional 50m foundation outside loaded local chunk bounds and replaces only the overlapping regional segments with 10m detail under a fixed combined vertex budget; no global 10m runtime parse, new projection authority, or parallel refinement scheduler is introduced.
- **User-visible change:** At near/max globe zoom in the Hong Kong / Pearl River Delta coverage, coastlines use materially finer local geometry while the surrounding regional coastline remains continuous. The same geographic focus selects the same local region across centered desktop and off-center/mobile composition; manual exploration can move refinement only after the real inspected surface moves away from that focus.
- **Review fixes:** The initial source proved the local 10m feed but a new numeric test compared wrapped longitude by exact floating-point identity; `08ec2fb` changed that assertion to numeric tolerance without touching production behavior. Automated P1 review then found local chunks were replacing the whole near layer; final Source `1882b8f` merges regional 50m coverage with a 10m replacement patch, removing only regional segments inside loaded local chunk bounds and preserving a bounded combined vertex budget. Automated P2 review found quality rebuild could diverge the committed refinement key from the installed geometry; final Source preserves keyed near geometry across the quality rebuild and atomically replaces it only when the next quality/local refinement wins. Both review threads were verified and resolved on the final Source head.
