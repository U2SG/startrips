# PR #319 - Deterministic Home Base inference core

- **Source head:** `7a56cf74051cbd89493fea886f7ad6c6d8332378`
- **Scope:** Implements ST-027 / issue #232 as a deterministic, side-effect-free Home Base inference core. It derives bounded 25 km evidence regions from Journey route endpoints, applies the owner-defined candidate/suggestion thresholds and directional/leader-margin rules, emits stable evidence digests and dismissal behavior, and evaluates sustained Home moves against an open confirmed Home period. The final source keeps proposal onset separate from temporal currentness: move ordering is based on when each state independently reaches confidence, while isolated historical or late visits cannot borrow stale support to shift or revive a move. No server persistence route, Home Base write contract, Playback topology, sharing surface, or Home-presence rendering is wired to this module in this PR.
- **User-visible change:** This is the inference foundation for future Home Base suggestions rather than a newly exposed UI. Its observable contract is deterministic: repeated Journey history yields stable candidate/suggested/move_suggested/dismissed states, and sustained moves are not backdated by isolated old visits, revived by one late revisit after a newer sustained state, or suppressed by one isolated return to the old Home.
- **Review fixes:** Review/CFAA closed the full evidence-family rather than patching one fixture at a time: bounded pairwise metro clustering and deterministic medoid selection; balanced start/end support and region-relative runner-up competition; date/dismissal edge cases; dense-history bounding; sustained-window move onset; bounded/open confirmed-period handling; expiry of historical competition; candidate/suggestion currentness provenance; and final continuity splitting that separates a genuinely remote historical visit without treating the 90-day minimum span as a maximum allowed gap. The last sibling repairs preserve continuous/monthly and regular sparse long-term evidence while still detaching a remote old visit before an independently sustained newer block.
