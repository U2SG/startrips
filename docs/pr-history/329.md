# PR #329 - Productize the v12 signature loading clip

Addresses #302.

- **Source head:** `0d63c78aab52d11452487f3038f643bb39149c01`
- **Scope:** Implements the narrow ST-055 slice on top of the already-approved v12 identity from #299. `src/brand/startripsV12MotionSource.ts` commits the canonical authored timing/order dataset extracted from the approved standalone `startrips-logo-motion-v12.html` study, recording source SHA-256 `7931733faedeaea68f7999d8c2d95e0ee12f475466cbe9714d0b773987d25b91`. `src/brand/startripsSignatureTimeline.ts` exposes semantic `full` and `loading` clips from that one timing source; consumers request clip names rather than raw seconds, and the 3.6 s loading clip is intentionally remapped instead of uniformly scaling the 25.4 s authored study. `src/brand/startripsSignatureRuntime.ts` provides one interruptible rAF driver; `StartripsSignatureMotion.tsx` renders the existing committed `/brand/startrips-v12-wordmark.svg` geometry through fragment references, so no second path dataset is introduced. The existing `StartripsBrandLoader` now uses `clip="loading"`. Browser QA and core tests cover timing order, geometry consistency, lifecycle cancellation, bounded DOM/listener/driver counts, hidden/offscreen suspension, initial-hidden mounting and Reduced Motion.
- **User-visible change:** Initial/auth loading now uses a condensed v12 character motion instead of the old whole-wordmark breathe loop. The motion notices the star, transfers support through staggered front hooves before the rear legs, then settles back to the approved static v12 lockup in 3.6 seconds. Pointer or keyboard intent immediately wins and settles the mark; hidden/offscreen loaders stop their driver; a loader mounted while its tab is already hidden starts suspended and excludes the hidden interval from elapsed time; Reduced Motion shows the static final identity with no timeline scheduled. The loader remains non-blocking and preserves the existing Persistent Earth underneath it.
- **Review fixes:** Review P2 on Source `a6f9bad` found that an auth/atlas/shared loader mounted while `document.hidden === true` constructed the runtime with `visible=false` but called `runtime.start()` before synchronizing suspension. That could let the first visible frame consume the entire hidden interval and skip cycles. Final Source `0d63c78aab52d11452487f3038f643bb39149c01` calls `syncSuspension()` before `start()` and hardens the runtime so `start()` itself publishes `suspended/driver=0` when pre-suspended. A unit regression suspends before start, advances a fake clock by eight seconds with zero scheduled frames/elapsed time, then resumes and advances only from the visible interval. The browser lane now also mounts the product preview with `document.hidden` forced true from init: after 700 ms hidden it remains `cycle=0 / elapsed=0 / driver=0`, then resumes at about 100 ms visible elapsed rather than jumping a cycle. Pre-PR self-audit had already corrected the runtime wall-clock accounting, moved pose event boundaries onto the canonical semantic clip dataset, and replaced source-string cleanup assertions with executable fake-rAF lifecycle tests.
- **Follow-up:** Owner decision recorded 2026-09-13 clears the ST-055 human gate: the production canonical source is the extracted timeline dataset derived from `startrips-logo-motion-v12.html`; the desktop idle companion is explicitly deferred and not approved by this PR. Also deliberately deferred: 404/empty/error motion, confirmed-result/success excerpts, arrival/chapter excerpts, permanent animated Atlas chrome, and every #323-derived issue. `full` exists as the canonical semantic clip but is not placed into a persistent product surface by this slice.
- **Validation:** Exact Source `0d63c78aab52d11452487f3038f643bb39149c01` is based on `origin/main@6fed202e77b87450c6c82f57718351aa963ece19`. `git diff origin/main..HEAD --check` passed. `tsc --noEmit --pretty false` passed. `vitest run src/brand/startripsSignatureRuntime.test.ts src/brand/startripsSignatureTimeline.test.ts src/brand/StartripsBrandMark.test.ts --maxWorkers=1` passed 18/18 tests. `node scripts/qa-brand-signature-motion.mjs` passed on the exact Source: declared loading duration 3600 ms, measured consecutive cycle about 3604 ms, DOM node count fixed at 31 across two cycles, listener count fixed at 4, one active driver while running, hidden/offscreen driver count 0 with frozen elapsed time, initial-hidden mount holding `cycle=0 / elapsed=0 / driver=0` through the hidden interval and resuming from about 100 ms visible elapsed, pointer and keyboard interruption settling once without restart, and Reduced Motion driver count 0 with the final pose.
