# PR #682 - Measure Particle Earth render work under cover and budget

- **Source head:** `da80f7b49b417996ae4325da4700132abdaa5650`
- **Scope:** Adds `scripts/qa-perf-globe.mjs` and its own `perf-globe` workflow, which measure Particle Earth render work counts across the #247 scenarios. Overview idle, drag, near-LOD drag and focus flight run on an unfocused, fully revealed fixture; Route optics is enabled only for the covered narrative-update case. The other scenarios are Story partial, cover transition, stable cover, cover with narrative updates, reveal, synthetic hidden→visible and 5 cover cycles, plus a 6-viewport × 2-quality drawing-buffer matrix; the artifact is SwiftShader-only. The workflow fails on any render or refinement work while covered or hidden, a resumed first frame above one clamped step, any cover-cycle growth, or a drawing buffer over its profile's pixel or DPR cap. `__particleEarthDebug` gains cumulative render calls and points, the frame revision, the drawing-buffer size and refinement request counters. `wakeRenderLoop` now uses the same idle render state as `updateRenderLoopVisibility`, so a stable opaque cover no longer renders one invisible frame per narrative setter call. A Home camera seed holds the wake open until a frame has measured its settling.
- **User-visible change:** None visible. Behind fullscreen media the globe no longer draws while Playback updates temporal reveal or Route Point selection.
- **Review fixes:** Codex findings, all fixed and resolved. The overview fixture was route-focused and now runs unfocused. The workflow now fails on breaches of the covered-state budget, cover-cycle growth, the drawing-buffer pixel and DPR caps, and the resume clamp, which it previously only recorded. The paths filter now includes the route fixture and the QA entry. A Home camera seed under cover was postponed to reveal and now flies underneath.
- **Follow-up:** The #247 device frame-time / long-frame budget needs a real-device pass with the budget declared first; SwiftShader CI cannot close it. Reduced motion is not exercised, and low quality appears only in the budget matrix. Low quality drops below DPR 1 on large screens (0.851 at 1920×1080@2), a blur risk for #246's optical sign-off.
- **Validation:** Perf-globe baseline [run 37782872330](https://github.com/U2SG/startrips/actions/runs/37782872330) (harness only) vs. fix [run 37783657371](https://github.com/U2SG/startrips/actions/runs/37783657371), 3 repetitions each.
