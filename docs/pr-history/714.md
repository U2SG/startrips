# PR #714 - Start Journey creation from a one-sentence description

- **Source head:** `aa27551e91934570f54d7796b91d301d1b03b3b7`
- **Scope:** Composer create mode adds a one-sentence description form that drives the existing itinerary import panel as pasted text (new `sentence` prop). New pure `relativeJourneyDates` resolves a fixed set of Chinese relative date phrases against the local date when the reading has no calendar date. Without recognition, sentence requests are shaped by `journeySentenceToItineraryText` for the deterministic `text-itinerary/1` reader; pasted-text import is unchanged.
- **User-visible change:** Creating a Journey starts from 「用一句话描述这段旅程」; read places, order and dates are reviewed before applying; inferred dates are labelled 「按今天推算」 until edited.
- **Review fixes:** Scoped the model-free sentence splitter to sentence requests so the existing pasted-text path keeps its behavior. Codex review: the splitter now consumes 了/趟 after 去 and keeps explicit dates written with 号. Owner review: a sentence naming more than one time infers no dates and lists the phrases in source order, except two days joined as a span (5月3日到5月5日), which read as one range.
- **Follow-up:** Model-free splitter can split place names containing 从/去/在; model `partialDate` is not yet used to narrow an inferred month.
- **Validation:** Local `pnpm typecheck` and `git diff --check`. `composer-route-points` (shell-composer shard) now covers sentence → recognition → review → apply with recognition configured, the model-free fallback, and the multiple-times case, on a fixed clock with stubbed API responses; unit tests and browser QA are authoritative in GitHub Actions.
