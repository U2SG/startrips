# PR #274 - Keep Atlas chrome inert during globe point-picking

- **Source head:** `02e60c8f65eeb9445be4b1915617fd9bb94a638e`
- **Scope:** Extend `claimInertOwnership` so a focus trap does not release `inert` after another owner mutates that flag during the trap lifetime; add default-node ownership cases and a live desktop Composer globe-pick browser guard over the real Atlas header, Journey rail and active Journey surface.

The implementation keeps React as the globe-pick owner and confines the product fix to the shared focus-trap claim/release path.
