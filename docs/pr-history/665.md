# PR #665 - Frame the 3D Journey Book tightly at rest and pull back while a page turns

- **Source head:** `64664e424861b637ea3dbdc92f27d140cf473048`
- **Scope:** `bookFrame` in `journeyBook3dModel.ts` takes a `lift`, the free-edge height in page-height units; `lift = 1` reproduces the #634 frame. `fitBookFrame` fits a frame from a top and writes into a supplied object. `restBookFrame` frames the rest state at the hover edge height `HOVER_EDGE_HEIGHT = sin(π·EDGE_LIFT)`. `flightFrameTop` returns `max(restTop, measuredTop + FRAME_MARGIN)`. `JourneyBook3dScene` measures, on every rendered frame, the highest screen-up point of the sheet in flight's deformed vertices (curl and twist included) with no per-frame allocation, and frames the camera from it. `pixelsPerUnit`, `spineX`, `pageWidthPx`, `pageHeightPx` and `faceRect` read the rest frame. `JourneyBook3d` publishes a DEV-only `data-qa-book-flight` readout.
- **User-visible change:** A settled 3D Journey Book fills about 85% of a wide stage's height, up from about 68% after #634. While a page turns, the camera pulls back exactly as far as the sheet rises, then returns as it lands. A desktop edge hover does not move the camera.
- **Review fixes:** Codex P2 "Keep the early-turn page inside the frame" (the hover pose stood about 0.009 world units above the first Source's rest frame). Fixed in 64664e42. The rest frame now holds the hover edge, and a turning sheet is framed from its measured geometry instead of a sin(π·frac) proxy.
