# PR #639 - Play the full signature clip from the Atlas wordmark and on invitation accept

- **Source head:** `13a83a6126f155a4460cb00a42829d97846c9fdb`
- **Scope:** The approved V1 `full` signature clip is used at two brand nodes. It plays as a one-shot, click-through, `aria-hidden` overlay that is mounted only while active. `StartripsWordmarkSignatureButton` (`src/brand/StartripsSignatureMoment.tsx`) makes the desktop and mobile Atlas wordmark a ≥44 px button labelled `播放 Startrips 动画`. It plays the clip in place over the identical v12 geometry and hides the static art only while the clip runs. `AuthGateway` starts the clip on invitation accept, in the same batch as the refetch and revision bump, and releases it when WorkspaceGate is ready; the brand loader's short clip is hidden meanwhile. `StartripsSignatureMotion` gains an optional `onEnd`, which fires once on settled, interrupted or reduced. The pure phase reducer and its Tier 1 fade live in `src/brand/signatureMoment.ts`. Clip geometry, timeline, colours and assets are unchanged.
- **User-visible change:** Clicking the Startrips wordmark plays the full goat-and-star signature once in place. Any click, key or Escape skips it. Accepting an invitation plays the same clip while the Atlas opens, and it fades as soon as the Atlas is ready. Nothing plays under reduced motion.
- **Review fixes:** The static-markup test now asserts on the rendered `<button>` element itself: React 19 server rendering hoists an image preload `<link>` ahead of the tree, so the first tag is not the button.
