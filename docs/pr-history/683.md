# PR #683 - Measure and reduce authenticated API latency

- **Source head:** `5aa4d7d6e782e06901aa5c4bfc6da58886b1df6b`
- **Scope:** Add a frozen in-process API latency harness (`server/bench/api-latency.ts`, `perf-api` workflow with PostgreSQL 17) that reports DB round trips per request by table, latency median and range, bytes, errors and work counts. Three measured changes land on top of it. `requireAtlasAccess` reuses the already-resolved session and reads member plus live Atlas in one query instead of `getActiveMember`. `updateJourneyForAtlas` writes Route Points with one `UPDATE ... FROM (VALUES ...)` plus one insert, using per-column preserve flags. Better Auth `session.cookieCache` is enabled with `maxAge: 60`, approved by the owner. The Google sign-in integration test now merges cookies by name. No migrations; `auth-schema.ts` is unchanged.
- **User-visible change:** Faster authenticated requests and Journey saves. Queries per authenticated app request go from 7 to 1, the load path from 91 to 27, and a 64-point PATCH from 82 to 13 (p50 53.4 ms to 13.3 ms in CI). A revoked session can keep authenticating for up to 60 seconds; Atlas membership removal is still immediate.
- **Review fixes:** Codex P1 (negative synthetic longitudes) is fixed in the harness commit by normalizing into [-180, 180). Codex P2 (leaked queries did not fail the run) is fixed: the harness now reports leaked queries in the step summary and fails on any. Codex cleared CODE Source 93a75507; the code was then rebased conflict-free onto origin/main acd54fbe (after #681 and #685, which change only client bundling and QA scripts, no server overlap), so no new review was requested.
- **Follow-up:** Owner proposals: run `organization/list` in parallel with `atlases/current` in AuthGateway; drop `storageKey`/`storageDriver`/`uploadedByUserId` from the owner Journey payload (hygiene); consider `disableCookieCache` on the account-identity, password and email-change routes; optionally add a `paths:` filter to `perf-api`. The journeys-list cost is now dominated by serializing about 785 KB of Route Points.

Latency medians vary between runners, so query counts are the primary number. Locally: typecheck, `git diff --check` and `pnpm auth:schema` (no change).
