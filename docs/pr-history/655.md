# PR #655 - Bring the remaining Story controls into the control family

- **Source head:** `e29f06c76bb1b9479805c4d1ab6442d56d300607`
- **Scope:** CSS only, no TSX. The Story controls #653 left unmigrated now read the `:root` `--control-*` tokens from their own selectors. `.story-point-note__expand` and `.story-point-note-sheet__close` are quiet 44px pills with no border or fill, so the note slot geometry is unchanged. `.story-media-rail__organize` and `.starlight-media-state > button` (retry, view next, renewal retry) are secondary pills. `.story-media-organizer__check` changes from a round khaki badge to the family square check: a 20px box with a `--control-select` fill and a `--control-primary-ink` mark. The tile stays the target and keeps `aria-pressed` and its keyboard path, and the selected tile outline, tile-action circles and organizer focus ring use the same tokens. In Journey Stream, `__icon` and `__side` are 44px circles, and `__side` keeps the neighbouring Journey's `--side-accent` ink. The soundtrack toggle has a cyan `aria-pressed` state, `__text-action` is a secondary pill and the `__play` indicator is a 52px circle. `.revealed-note__toggle` grows from a 32px box to a 44px secondary pill in both Story and the Journey Book. Only revealed-note.css changed, and the Book still mounts the toggle on picture plates. Stream and Book render inside `.living-atlas`, whose `button:where(...)` defaults (`font`/`color: inherit`, 1px focus ring) at (0,1,1) overrode their single-class rules, so the new selectors are rooted on `.journey-stream` and `.revealed-note`. All of these use the 2px `--control-focus` ring, `scale: 0.97` on press under `no-preference` and fine-pointer-only hover. Dead rules removed: `.journey-story__media-order` (base, mobile and its `:has(confirm)` entry), `.journey-story__media-move-bar` (base and mobile), the mobile `.journey-story__media-controls` bar with its `__media-nav` child (rendered only when `!mobileLayout`, which uses the same query as the compact block), and the `.living-atlas.is-mobile-v2 .journey-story…` rules (Story is portaled to `<body>`). The #531 comment that cited them was reworded.
- **User-visible change:** Story's point-note, organize and retry actions, the organizer selection check and the revealed-note toggle now match the control family: pills, a square cyan check, one 2px acid focus ring and a small press response. The revealed-note toggle is a full 44px target in Story and the Journey Book. Journey Stream's header and side controls are dark-glass circles and a pill in the family sans type, instead of borderless serif text in inherited colour.
- **Review fixes:** None.
- **Follow-up:** `.story-notes-editor__save` is kept. The rule is inert because `.story-notes-editor__actions button` outranks it, but StoryNotesEditor.tsx still uses the class, so it fails the brief's grep precondition for deletion. The mobile `.journey-story__fullscreen-entry` position rule is also dead, since the entry renders only inside the desktop media nav, but #653 did not list it. Not migrated: the organizer's destination cards and grip, its `aria-current` khaki tile border, and the mobile Viewer cluster, video nav, quick-recap and autobrowse pills, sort-done, manage-bar and sheet-row literals that #653 listed.
