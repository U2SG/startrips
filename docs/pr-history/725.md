# PR #725 - Install the CI CJK font from a pinned release instead of the Ubuntu mirror

- **Source head:** `15862856f44339fb6a74ad4f8f703fef52dfc454`
- **Scope:** New `scripts/ci-ensure-cjk-font.sh`: when no zh font is present it downloads `notofonts/noto-cjk` `Sans2.004/18_NotoSansSC.zip` from GitHub, verifies a pinned SHA-256 before extracting (also on cache hits), installs Regular/Medium/Bold and the licence, refreshes fontconfig and asserts a zh font; the APT install stays only as a bounded fallback. In `keepsake-render` the font work is its own 5-minute step after an `actions/cache` step keyed by asset + sha. New contract test `scripts/ci-ensure-cjk-font.node-test.mjs` in quick-checks.
- **User-visible change:** None (CI infrastructure).
- **Review fixes:** None requested.
- **Follow-up:** The `keepsake-render` job's 10-minute ceiling still bounds the worst case where both the FFmpeg and font fallbacks run.
- **Validation:** Local `bash -n`, `node --check`, `git diff --check`; the contract test passed under Ubuntu noble (WSL).
