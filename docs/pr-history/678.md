# PR #678 - Build road graphs on demand from Overpass corridors

- **Source head:** `028389f6afb953cb052f0496f5051a1f28a253f7`
- **Scope:** Add a `routing-builder` sidecar that fetches only the roads around a requested route from Overpass, builds a small OSRM graph with the pinned image and the country-access walking/cycling profiles, proxies `route`/`nearest` to it, and evicts graphs when idle (30 min TTL, 4 live, 3 GB disk cap, one build at a time). Modes with a static `ROUTING_OSRM_*_BASE_URL` keep their behaviour; modes without one use the builder when `ROUTING_GRAPH_BUILDER_URL` is set. Candidate hard gates and the `osrm` provider value are unchanged; no migrations. `deploy-main.py` builds, health-checks and rolls back the builder.
- **User-visible change:** Road candidates and nearby road points work for any new Journey without preloaded road data. While a graph is prepared the editor shows the phase, then the candidates; failures name the reason (road data unavailable, area too large, no roads).
- **Review fixes:** The P2 thread is fixed: corridor queries now also fetch `route=ferry` ways along every leg for every profile, so a member who allows ferries can get a ferry candidate; the profile and ferry consent still decide acceptance. The owner authorized commit, PR, merge, deployment and removal of the old graphs.
- **Follow-up:** Deploy through the canonical main script, switch the three modes to on-demand graphs on the host, verify real candidates, then retire the static OSRM containers and their datasets. Measure builder memory on a long corridor and watch public Overpass availability.
- **Validation:** [Source CI](https://github.com/U2SG/startrips/actions/runs/37735487024) passed quick-checks, core, keepsake-render and all eight browser QA lanes; ledger/verify failed only because this ledger was absent. Locally: typecheck, builder/routing/route/config unit tests, `pnpm qa:routing-builder` against the real pinned image with an Overpass fixture (all modes, eviction, every failure code), and one live overpass-api.de corridor that built in 71 s and routed `Ok`.
