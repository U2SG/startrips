A user expands one record to edit its details, while Up / Down / More stay reachable on every row; More contains Delete, disabled boundary moves remain visible, and reorder/delete/keyboard focus stay attached to the same logical Route Point.

Entering globe-pick mode closes any open route-point More menu so globe-pick Escape retains ownership. Delete moves focus to a deterministic surviving draftId, and reorder keeps focus/scroll on the moved record instead of the former index.
