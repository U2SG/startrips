# PR #688 - Bound every 3D Journey Book phone wait with a named failure

- **Source head:** `0920fd7e534326c24583650e9b34aaf6deeaa977`
- **Scope:** `scripts/qa-journey-book-3d.mjs` gains a `bounded(label, promise)` helper with a 30 s step budget. It wraps every phone CDP `Input.dispatchTouchEvent` (named per step, e.g. `touchMove 7/12`), every `page.evaluate` readout and pixel read, and the End/Home key presses. Screenshots, phone taps and focus calls pass the same timeout explicitly. The 120 s settle and flight waits now fail with the wanted face or progress plus the stage's current `data-qa-book`/`data-qa-book-flight` readout instead of a bare Playwright timeout. No timeout was raised, no retry was added and no assertion changed.
- **User-visible change:** None.
- **Review fixes:** Codex on `7ef55b7d` noted that `page.screenshot` in `sample()` was still unbounded. The follow-up commit gives screenshots, taps and focus the step timeout. Codex found no issues on it (`7cfaa3eb`, rebased onto `f5afa179` as `0920fd7e` with no change to this file).
- **Follow-up:** Desktop `page.mouse` moves are still unbounded CDP input; no stall has been seen there. The phone touch drag is about half the phone part (14–31 s) because each of its 14 events waits for a DPR 3 SwiftShader frame. `story-media-handoff` (untouched) failed in 2 of 4 story-media samples on this PR: run 37890273683, and run 37896703576 attempt 1 on `story-video-fullscreen-playing-slow-decode-rapid-back`. It passed on attempt 2.
- **Validation:** The mechanism was cap exhaustion, not a phone hang. Before #685, the 6 distinct `journey-book-3d` timeouts all started the phone session 701–711 s into the 720 s suite and were killed 1–10 s later, mid-touch-drag (line 525/544) or mid-`sample` (line 190). Those were runs 37793024673, 37793526913, 37797493335 and 37801934911. After #685 the phone part passed 16/16 distinct samples at 29–62 s before this PR. On this PR, the phone part passed 5/5 on `7ef55b7d` (57, 75, 72, 55 and 73 s; runs 37890251056 and 37890273683). It passed 5/5 on `7cfaa3eb` (50, 55 and 38 s on run 37892920256 attempts 1–3; 56 and 72 s on dispatched run 37892930291 attempts 1–2). It passed in 36 s on rebased Source run 37896703576, where every browser-qa lane passed, story-media on attempt 2. Turns, drags and last-spread passed on every run. Locally: `pnpm typecheck`, `git diff --check` and `node --check scripts/qa-journey-book-3d.mjs`; all browser QA ran in GitHub Actions.
