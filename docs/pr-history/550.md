# PR #550 - Preserve paused video through signed-read renewal

- **Source head:** `34af74c23208ff1237cb4ffc87a411a1ecf452ae`
- **Scope:** Keep a paused Story video's decoded frame, playback time, and native settings through signed-read renewal, failed read URLs, failed video bytes, and Retry. Distinguish a new signed read by generation even when its URL is unchanged, while keeping one persistent video element.
- **User-visible change:** A paused video stays visible while its access is renewed. If renewal fails, the original frame and time remain available with a Retry control; after successful retry the same video resumes at its previous position and remains clickable. Fullscreen hands that paused position back to Story before inline renewal.
- **Review fixes:** Independent review found that a same-URL Retry could leave the button disabled without another byte request. Source now reloads the existing video for a new read generation, and browser QA covers the same URL after a real byte failure along with delayed reads, delayed bytes, fullscreen Close, screenshot coverage, and native hit targets.
