# PR #741 - Declutter the audiobook player and offline library

- **Source head:** `d484d228afaee96f046d7e130320d6910b9b75c3`
- **Scope:** Removes secondary labels from the soc audiobook UI. The page row becomes `‹ [n] / N ›` and jumps on submit or blur. The time row shows elapsed time, centred speed and remaining time. The primary button shows ↺ once the book has ended. The speaker appears on the active passage only in 人物分声 mode. The settings panel and download progress are compact, and download progress is a thin bar. The mini player gets a bottom progress line. Offline library cards open from the whole left block, with 删除 as a sibling button. Every accessibility label, role and state is kept. `scripts/qa-soc-web.mjs` follows the new UI.
- **User-visible change:** The listening reader, mini player and offline library show less text, and progress is shown as bars instead of sentences. Submitting the page already shown no longer restarts it, and an emptied page field restores the current page.
- **Review fixes:** None.
- **Follow-up:** The primary button and the settings control share the accessible name 从头重听.
- **Validation:** `git diff --check` and `node --check` on the QA script. Earlier in development, typecheck, 76 unit tests and a local web QA run also passed. The ci.yml soc-client-only path and the Source soc.yml run (web, android, ios) on GitHub are authoritative.
